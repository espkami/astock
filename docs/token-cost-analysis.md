**当前模型 qwen3.6-plus：标准场景 ¥1.35/天，¥41/月。**
基于最新实测数据（4462条新闻，近48小时实采360条/天）和系统架构变化（新增热搜源、匹配率实测47.4%）全面重算。

数据来源：系统实测（截至 2026-05-24，DB 4462条新闻 / 824条匹配结果）

## Token 消耗拆解

### 变化说明（相比上版 2026-05-20）
- 新增热搜来源：每30分钟采集百度/微博/抖音热搜，增加约95条/天
- 匹配率实测：历史数据实测 47.4%（824/1737），上版估算60%偏高
- keywords prompt 优化：词根提取替代描述词
- 当前模型：qwen3.6-plus（Qwen3-235B）

### 分类阶段（每条新闻）
- batch 大小：20条/次
- 每条均摊：235 input + 90 output = 325 tokens

### 匹配阶段（每条进入匹配的新闻）
- 实测匹配率：47.4%
- 单条：2,300 input + 300 output = 2,600 tokens

## 降本建议

匹配阶段占总Token的 79%，是降本核心：

1. 只匹配有情绪的新闻（跳过neutral约52.6%）：月费 41 → 21元
2. 换 DeepSeek-V3：月费 41 → 11元
3. GLM-4-Flash 免费额度：日常流量完全够用
4. 减少 top_k 从5→3：output减少40%，节省约3元/月
